# SODET — sitio web

Landing page de SODET (Soluciones digitales en tecnología): software de gestión asequible para negocios pequeños en Colombia.

- `index.html`: la página completa (HTML, CSS y JS en un solo archivo).
- `apps-script/`: script de Google Apps Script que recibe el formulario de contacto, guarda cada solicitud en Google Sheets y envía un aviso por correo. Instrucciones en `apps-script/LEEME.md`.

Publicado con GitHub Pages desde la rama `main`.
